# Forest Fire Risk Analysis

An Intelligent System for analyzing forest fire potential based on environmental data in Indonesia.

## About the Project

Forest fires are an environmental problem that can cause significant damage to ecosystems, biodiversity, and human activities.

This project aims to develop an Intelligent System that analyzes environmental conditions to assess forest fire potential. The system is designed as a software prototype using historical environmental data.

## Project Objectives

- Analyze environmental factors related to forest fires.
- Prepare and process historical environmental datasets.
- Develop machine learning models for fire occurrence analysis.
- Explore the integration of Neural Network and Fuzzy Logic.
- Visualize analysis results through a dashboard and geographical risk map.

## Dataset

The project uses an Indonesian forest fire dataset containing historical records and environmental variables.

The dataset source, description, and attribution will be documented here.

## Planned Methods

- Neural Network
- Fuzzy Logic

The final modeling approach will be determined based on dataset characteristics and experimental results.
